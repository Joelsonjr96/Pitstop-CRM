# Pitstop-CRM
CRM de pós-venda para oficinas mecânicas — (Next.js 16, TypeScript, Supabase). Gestão de clientes, veículos, registros de serviços, previsão de manutenção automática (calculateNextMaintenance),   retenção via contatos WhatsApp (wa.me) e dashboard de KPIs (atrasados, próximos, faturamento em risco).
